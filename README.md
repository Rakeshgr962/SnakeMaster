# SnakeMaster Game 🐍

[![JavaScript](https://img.shields.io/badge/javascript-ES6+-yellow.svg?style=flat-square)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
[![License](https://img.shields.io/github/license/Rakeshgr962/SnakeMaster?style=flat-square)](LICENSE)

An interactive, responsive implementation of the classic arcade Snake game built from scratch using vanilla JavaScript and the HTML5 Canvas API.

---

## ✨ Features
- **Canvas Rendering Engine**: Fast, smooth frame rendering with requestAnimationFrame API.
- **Dynamic Speed Scheduling**: The game increases in velocity and difficulty as the score scales.
- **High Score Persistence**: Locally persists records using browser `localStorage`.
- **Custom Audio & Visuals**: Fluid movement animations and collision response visual cues.

---

## 🛠️ Tech Stack
- **Core Engine**: JavaScript (ES6)
- **Rendering Context**: HTML5 Canvas
- **Style System**: Responsive CSS3

---

## 🚀 Getting Started

### Run Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Rakeshgr962/SnakeMaster.git
   cd SnakeMaster
   ```

2. **Open the Game**:
   Simply double-click `index.html` or open it with any web browser to play.
